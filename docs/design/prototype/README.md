# Sherpa — кликабельный HTML-прототип

Статичный сайт без сборки и внешних зависимостей (чистые HTML/CSS/JS). Данные вымышленные, SSH не используется.

Запуск: `python3 -m http.server 10005 --bind 0.0.0.0 --directory docs/design/prototype`, затем открыть `http://localhost:10005/`.

Что внутри: «Дом» (список серверов, группы, теги, поиск, проверка), вкладки рабочих столов, оконный менеджер (перетаскивание, ресайз, сворачивание, привязка к краям, blur), панель задач с лаунчером и треем, утилиты (терминал, файлы + редактор, монитор, диски, сеть, система, логи, планировщик, Docker, уведомления, настройки) и модальные окна MVP (первый запуск, форма, импорт, host key, подтверждение опасных действий).

Полезные параметры URL (для демо и скриншотов): `?desk=web-01&apps=terminal,files,net:fw&launcher=1`, `&notify=1`, `&overview=1`, `&lost=1`, `&light=1`, `?modal=first|form|edit|import|hostkey|hostkey1|danger`, `&fast=1` (без задержек и первого запуска), `?selftest=1` (автопроверка: открывает все утилиты и вкладки, результат в заголовке страницы `SELFTEST OK/FAIL`).

Дополнительные утилиты (`apps3.js`): веб-серверы и SSL, базы данных, безопасность, сниппеты, мультисервер, туннели, бэкапы, сравнение конфигов, сетевые инструменты, журнал Sherpa, заметки и секреты; виджеты на обоях (контекстное меню рабочего стола → «Виджеты…»).

Файлы: `core.js` — DOM-хелперы, модальные окна, рабочий стол и оконный менеджер; `data.js` — фейковые данные; `apps.js`, `apps2.js`, `apps3.js` — утилиты; `main.js` — «Дом», диалоги MVP, горячие клавиши, самотест. Шрифты — системные (JetBrains Mono, если установлен, иначе DejaVu Sans Mono).
